A API da That's Me usa **dois estilos de paginação** dependendo do grupo de endpoints:

- **Endpoints `/v1.0/*`** usam `limit` + `offset` (estilo SQL clássico)
- **Endpoints `/dashboard/*` e `/v1.0/webhooks/{id}/deliveries`** usam `page` + `limit`

## Estilo 1: `limit` + `offset` (v1.0)

Usado pelos endpoints principais de integração.

| Parâmetro | Tipo | Padrão | Descrição |
|---|---|---|---|
| `limit` | number | 50 (varia por endpoint) | Itens por página |
| `offset` | number | 0 | Posição inicial (`offset = (página - 1) × limit`) |

### Exemplo

```bash
# Segunda "página" de 10 em 10 itens (offset 10, limit 10)
curl "https://api.thatsme.com.br/api/v1.0/invitations?offset=10&limit=10" \
  -H "Authorization: Bearer SUA_API_KEY"
```

### Resposta

```json
{
  "data": [...],
  "total": 150,
  "limit": 10,
  "offset": 10
}
```

Para saber se há mais páginas, compare `offset + data.length < total`.

### Endpoints com estilo limit/offset

| Endpoint | Padrão | Máximo |
|---|---|---|
| `GET /v1.0/events` | 50 | — |
| `GET /v1.0/events/{id}/badges` | 50 | — |
| `GET /v1.0/badges` | 50 | — |
| `GET /v1.0/invitations` | 50 | — |
| `GET /v1.0/recipient-invitations` | 50 | — |

## Estilo 2: `page` + `limit` (dashboard + webhook deliveries)

Usado pelos endpoints de analytics e auditoria.

| Parâmetro | Tipo | Padrão | Descrição |
|---|---|---|---|
| `page` | number | 1 | Número da página (a partir de 1) |
| `limit` | number | 20 (varia por endpoint) | Itens por página |

### Exemplo

```bash
curl "https://api.thatsme.com.br/api/dashboard/winners/evt_a8Kq2?page=2&limit=20" \
  -H "Authorization: Bearer SUA_API_KEY"
```

### Endpoints com estilo page/limit

| Endpoint | Padrão | Máximo |
|---|---|---|
| `GET /dashboard/events/list` | 20 | — |
| `GET /dashboard/winners/{event_id}` | 50 | 50 |
| `GET /v1.0/webhooks/{id}/deliveries` | 20 | — |

## Percorrendo todas as páginas

<CodeGroup>

```javascript Node.js (limit/offset)
async function fetchAllInvitations(apiKey) {
  const results = [];
  let offset = 0;
  const limit = 50;

  while (true) {
    const res = await fetch(
      `https://api.thatsme.com.br/api/v1.0/invitations?offset=${offset}&limit=${limit}`,
      { headers: { Authorization: `Bearer ${apiKey}` } }
    );
    const json = await res.json();
    results.push(...json.data);
    if (offset + json.data.length >= json.total) break;
    offset += limit;
  }

  return results;
}
```

```python Python (limit/offset)
import requests

def fetch_all_invitations(api_key):
    results = []
    offset = 0
    limit = 50

    while True:
        res = requests.get(
            f'https://api.thatsme.com.br/api/v1.0/invitations',
            params={'offset': offset, 'limit': limit},
            headers={'Authorization': f'Bearer {api_key}'},
        )
        data = res.json()
        results.extend(data['data'])
        if offset + len(data['data']) >= data['total']:
            break
        offset += limit

    return results
```

</CodeGroup>
