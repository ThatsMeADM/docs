## Base URL

```
https://api.thatsme.com.br/api
```

All v1.0 endpoints are prefixed with `/v1.0` after the base URL (e.g. `https://api.thatsme.com.br/api/v1.0/events`).

## Authentication

All v1.0 endpoints require an API key sent as a Bearer token:

```bash
Authorization: Bearer your_api_key
```

Generate your API key at **Settings → Integrations → Generate API Key**.
The key is shown once at creation — store it securely.

<Warning>
  A **FREE** plan cannot use the API at all — all requests return `403 Forbidden`.
  You need at least the **Starter** plan for read access and **Pro** plan or above
  for certificate emission and webhooks.
</Warning>

## Rate limits

Rate limits are per organization (not per IP), applied across all API keys you own.

| Plan | Rate limit |
|---|---|
| Free | No access (403 Forbidden) |
| Starter | 100 req/min |
| Pro / Business | 1,000 req/min |
| Enterprise | 10,000 req/min |

Rate limit responses return HTTP 429 with `Retry-After` header. See [Tiers](/en/api/v1/tiers) for full details.
